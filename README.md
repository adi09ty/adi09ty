#### Featured Projects

**[ETL & Reporting API](https://github.com/adi09ty/etl-reporting-api)**
Spring Boot service that ingests order CSVs from S3-compatible storage and exchange rates from a public REST API, validates and loads them into MySQL, and serves currency-converted reports. Retries, idempotent loading, scheduled jobs, 80 tests.

**[Wallet & Payments Ledger](https://github.com/adi09ty/wallet-ledger-service)**
Atomic top-ups and transfers with idempotency keys and an immutable, append-only ledger. Row-level locking prevents overdrafts and deadlocks under concurrent transfers.

**[URL Shortener](https://github.com/adi09ty/url-shortener)**
Link shortener with expiry, per-day click analytics, Redis cache-aside caching with circuit-breaker fallback, and per-client rate limiting.

**[Inventory Management API](https://github.com/adi09ty/inventory-management-api)**
Product/supplier/stock tracking with JWT auth, role-based access control, optimistic locking, and Swagger/OpenAPI docs.
